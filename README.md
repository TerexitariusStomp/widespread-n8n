# n8n-nodes-widespread

n8n community node for the [Widespread](https://github.com/TerexitariusStomp/widespread-bridge)
protocol — verified-work bounty discovery for agent workflows.

Operations: List Bounties · List Markets · Feed Search · List Runners ·
Get State — all against the public bridge (or a self-hosted base URL).
Non-custodial read surface; the signed earn loop runs through the
[Widespread MCP server](https://widespread-bridge.widespread.workers.dev/install).

## Install

```sh
npm install n8n-nodes-widespread
# n8n → Settings → Community Nodes → Install → n8n-nodes-widespread
```

Verified-community listing submitted to n8n; self-hosters can also install
directly from npm.
